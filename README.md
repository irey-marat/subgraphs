# Subgraphs (Недографы)

## СВЕДЕНИЯ

### Запуск

1. dist/subgraphs.user.js устанавливаете в Тамперманки
2. затем в диалоговом окне загрузки на странице запуска вам будет предложено загрузить ZIP - это subgraphs_db.zip

### Содержимое

Папка src - это subgraphs.user.js, но в "разобранном виде".
То же самое с папкой subgraphs_db - это содержимое subgraphs_db.zip.
Для установки они не нужны.

subgraphs_db - это данные игры - спрайты, карты, координаты переходов и точек спавна. Игра загружает это содержимое в indexedDB вашего браузера.
